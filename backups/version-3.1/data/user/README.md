# Persönliche Daten

Persönliche Notizen, Lernstände, Favoriten und eigene Links gehören nicht in die kanonische Wissensbasis.

Die Anwendung verwaltet sie lokal als versioniertes Benutzerprofil im Browser. Über Export und Import kann dieses Profil als `azure-digital-brain-user-profile.json` gesichert oder auf einen anderen Browser übertragen werden.

`user-profile.example.json` dokumentiert das offene Austauschformat. Die Beispieldatei enthält keine echten persönlichen Daten.
